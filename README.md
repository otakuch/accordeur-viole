# Accordeur pour viole de gambe à 7 cordes

Page web autonome pour accorder une basse de viole à 7 cordes (La, Ré, Sol, Do, Mi, La, Ré).

- Manche visuel : 7 cordes et 7 frettes, chacune dans sa couleur.
- Note de référence pour chaque corde à vide et chaque case.
- Diapason réglable : 392, 415 ou 440 Hz, ajustable au hertz.
- Écoute au micro : une jauge indique l'écart en cents avec la note visée.
- Analyse possible d'un enregistrement si le micro n'est pas disponible.

Le son du micro est analysé dans le navigateur. Rien n'est envoyé ni enregistré.

## Mise en ligne

Le micro exige une page servie en HTTPS. Avec GitHub Pages :
Settings, Pages, Source « Deploy from a branch », branche `main`, dossier `/ (root)`.

## Limites

Tempérament égal uniquement. Les notes de référence sont des sons de synthèse.
